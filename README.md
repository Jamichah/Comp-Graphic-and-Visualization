# Comp-Graphic-and-Visualization

Final Project: 3D PlayStation 5 Gaming Setup

Project Overview

As my final project for CS 330, I used C++ and OpenGL to make a 3D PlayStation 5 game setup. A wooden gaming desk, a monitor showing the PlayStation welcome screen, a PS5, a keyboard, a mouse, and two DualSense controllers are all in my scene. To make the space feel more complete, I added a wooden floor and wallpaper with clouds on it. I used 3D transformations, texture mapping, lighting, and camera controls to make an interactive world for this project. By putting together simple geometric shapes into recognizable items and using programming skills to set up and render a 3D scene, this project shows that I can do both.

How Do I Approach Designing Software?

Before I start making software, I make sure I understand what needs to be done and divide the project into smaller, more manageable pieces. I learned how to look at real-world items and figure out which basic 3D shapes could represent them through this project, which helped me improve my design skills. For instance, I built the desk, monitor, and PS5 machine out of boxes. The controllers and mouse were made out of spheres and cylinders. When designing a scene, I also learned how important it is to pay attention to proportions, placement, and how things look all together.

I started the design process by picking a gaming setup I was already familiar with and making a list of the things I wanted to include. After that, I planned out the shapes each object would need and slowly added textures, lighting, and details. During the job, I made changes whenever something didn't look right. This taught me how important it is to plan before I code while still being able to make changes for the better. I can use the same method for future software projects by figuring out what they need, making a plan, and breaking down big jobs into smaller ones.

How Do I Approach Developing Programs?

This class taught me how to handle programming by trying new things, testing them, and always getting better. Building my scene one object at a time instead of trying to make everything at once was one of the most important things that helped me learn. I used reusable methods to make creating objects easier and cut down on code that was done over and over again. As an example, I made helper functions for drawing cylinders, spheres, and boxes. This made it easier to build many objects while keeping the code clean.

One important thing that helped me finish my job was iteration. Objects often needed to have their size, rotation, and position changed to make them look real. For some reason, the monitor was too far away, the controllers were too close to the desk edge, or the PS5 needed to be moved. I learned how to find the exact values that needed to be changed and test the results instead of starting over. I also worked through problems with lighting, textures, and moving the camera. By reaching each milestone, I felt more sure in my ability to fix bugs in my code and see how small changes could affect the whole scene.

The way I develop software has changed over time. Now, I value testing individual parts, writing well-organized code, and making small changes more than changing many things at once. These tips helped me finish the project and will continue to help me with future programming tasks.
